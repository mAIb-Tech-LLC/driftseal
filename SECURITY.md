# Security policy

Report vulnerabilities privately to **support@maib.io**, subject **DriftSeal security disclosure**. Include a minimal reproduction, affected version and impact. Do not send live secrets or unrelated user data. Do not test neighbouring mAIb services under this policy.

The initial supported release is 0.1.x. Security fixes will be documented in CHANGELOG.md. There is no bounty or response-time SLA.

Threat boundaries, limits and known coverage gaps are documented in [docs/SECURITY_MODEL.md](docs/SECURITY_MODEL.md). Reports and public badges do not certify software security.
